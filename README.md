# 站点介绍

> 一个托管在 GitHub Pages 上的个人趣味站点：小游戏合集 + 网页导航 + 各种前端小实验。

- **线上地址**：<https://ostarso.github.io>
- **仓库地址**：<https://github.com/OStarsO/OStarsO.github.io>
- **仓库信息**：创建于 2023-05-21，主要语言 JavaScript，公开仓库，已开启 GitHub Pages

## 站点简介

OStarsO.github.io 是用户 OStarsO 的个人主页/工具站，整站为纯静态 HTML/CSS/JS，直接通过 GitHub Pages 发布。目前首页（`index.html`）是一个「系统维护中」的提示页，带有一个代码卡片堆叠的动画背景，页脚自动显示当前年份与版权信息；各子栏目仍可正常访问。

## 站点结构

### 1. 小游戏（/小游戏/）

站点的核心板块，收录了约 25 款网页小游戏和前端小工具，首页用按钮宫格的形式罗列：

| 分类 | 内容 |
| --- | --- |
| 经典复刻 | 2048、吃豆人（pacman）、贪吃蛇、五子棋、推箱子、国际象棋、消消乐、打方块 |
| 敏捷/手速 | 水果忍者、切方块、盖塔楼、跑酷（简易版）、赛车游戏、球跑者 |
| 休闲对战 | 石头剪刀布、猜数字、翻牌消除、今天吃什么 |
| 趣味/整活 | 电脑蓝屏模拟器、逗猫、画画、股大爷 |
| 解谜/其他 | 趣味闯关（解谜）、st方棋动物游戏 |
| 工具向 | 密码安全度检测（公测） |

其中「国际象棋（bot 公测）」内置了对战机器人，「密码安全度检测」标注为公测阶段。页面基于 HTML5 UP 的 Phantom 模板（`assets/css/main.css` + jQuery），底部内置了反馈表单和第三方音乐播放器插件。

### 2. 搜索（/搜索/）

名为「ST导航」的搜索/起始页，v1.50：

- 支持搜索历史、搜索建议、快搜（百科/视频/豆瓣/微博/知乎/小说/新闻）
- 提供网址输入快捷后缀（www./m./.cn/.com 等键盘快捷栏）
- 支持夜间模式（`night.css`）、Service Worker 离线缓存（`sw.js`）
- 采用 RequireJS 模块化加载，同样内置音乐播放器

### 3. 网页导航（/网页导航/）

网址导航栏目，当前同样为「系统维护中」状态。

### 4. 测试（/测试/）

站长的前端实验田：包含模板测试页（`测试.html`）、加载动画测试等页面，用于试验各种效果后再应用到正式栏目。

### 5. 其他文件

- `404.html` — 自定义 404 页面
- `beian.html` — 备案提示页（内容为站长式调侃：「这网站不用备案的你不知道？」）
- `api.css` / `api.js` — 维护页的样式与打字机动画脚本
- `ip.json`、`OStarsO.jpg`、`l.jpg`、`server-icon.png`、`favicon.ico` — 静态资源

## 技术特点

- **纯静态托管**：无后端、无构建流程，HTML/CSS/JS 直接托管于 GitHub Pages
- **模块化目录**：按栏目分目录（小游戏/搜索/测试/网页导航），每个栏目自带 `index.html` 与资源
- **第三方增强**：接入讯飞音乐播放器、count.getloli.com 访问计数器、capsule-render 动态 README 头图
- **移动端适配**：各页面均设 `viewport`，部分页面限制缩放，偏向移动端体验
