> 仓库地址：<https://github.com/OStarsO/OStarsO.github.io>
> 分支：`maintain`（当前最新提交 `031f48d`，更新于 2026-10-20）
> 仓库共三个分支：`Bata`、`main`（默认分支）、`maintain`

---

## 一、这个分支是做什么的

`maintain` 分支是整个站点的**「系统维护中」专用版本**。

它是一个从 `Bata` 分支拉出的精简分支：把正式站点的全部栏目内容（小游戏、搜索、网页导航、测试等）删除后，只保留一个"维护提示页"及其所需的样式、脚本和静态资源。

典型用法：

- 站点需要停机维护、改版或迁移时，在 GitHub Pages 设置中把发布源临时切换到 `maintain` 分支；
- 访客打开 <https://ostarso.github.io> 看到的不再是正式内容，而是一张带动画的"系统维护中"提示页；
- 维护结束后，再把 Pages 发布源切回 `main` 分支即可恢复站点。

这样无需删除正式内容，就能一键让全站进入"维护状态"，正式代码仍完整保留在 `main` 分支中。

## 二、与 `main` 分支的区别

| 对比项 | `main` 分支 | `maintain` 分支 |
| --- | --- | --- |
| 定位 | 正式站点 | 维护提示页 |
| 首页 `index.html` | 整站内容入口 | "当前网站正在维护中，请稍后访问，具体详情请联系管理员！" |
| 栏目目录 | 小游戏 / 搜索 / 网页导航 / 测试 | 无，全部已删除 |
| 图片资源 | OStarsO.jpg、l.jpg、server-icon.png 等 | 全部删除，仅保留 favicon.ico |
| 体积 | 完整站点（约数百 KB + 图片） | 约 283 KB，仅 7 个文件 |
| README | 完整的站点介绍文档 | 仅 1 字节（基本为空） |

### 各文件说明

**`index.html`（核心页面）**

- 页面标题为"系统维护中"，正文提示：*"当前网站正在维护中，请稍后访问，具体详情请联系管理员！"*
- 背景是一组**代码编辑器卡片堆叠动画**：多张仿 macOS 窗口（红黄绿三点）的卡片先后完成倾斜、爆开、悬停上浮，随后随机"敲出"若干行代码线条，模拟"程序员正在抢修"的氛围
- 页脚自动获取当前年份，显示 `Copyright © <年份> OStarsO All Rights Reserved.`

**`css/api.css`**

维护页的全部样式，定义了：

- `.writing`：仿代码编辑器窗口（灰底 + 顶栏三色圆点）
- `.stack-container` / `.perspec` / `.card`：3D 透视卡片堆叠布局
- 三组关键帧动画：`tiltcard`（倾斜）、`explode`（爆开）、`writeLine`（逐行写代码）
- 响应式适配：≤1000px / ≤850px / ≤775px / ≤370px 逐级缩放

**`js/api.js`**

交互逻辑：

- 卡片倾斜动画结束后触发 `explode` 爆开动画
- 爆开结束后为每张卡片生成 5–10 行随机长度的"代码行"，并通过监听 `animationend` 实现一行接一行依次写入
- 点击卡片会把卡片随机甩出屏幕（`translate + rotate(-540deg)`）并淡出

**`404.html`**

自定义 404 页面，标题"404 - 页面迷失在星空中"：

- Canvas 绘制 600 颗星星向用户方向穿梭（近大远小、越近越亮）
- 随机生成流星拖尾
- "404"标题使用渐变色 + 辉光动画，提供"返回首页"按钮

**`beian.html`**

整活性质的备案提示页，内容为一段 ASCII 风格的调侃文字："这网站不用备案的你不知道？不知道就算了！滚！"。该文件在 `main` 分支中也存在，内容一致。

**`ip.json`**

GitHub Pages 自定义域名验证文件，记录 TXT 挑战值 `_github-pages-challenge-OStarsO`，与 `main` 分支中的相同。

## 四、小结

- `maintain` 是一个**单页维护分支**：只保留 `index.html` 维护提示页 + `404.html` + 必需的 css/js 和 favicon
- 页面通过纯 CSS 动画 + 少量原生 JS 实现"代码卡片爆开"效果，无任何第三方依赖
- 正式站点内容不受影响，仍完整保留在 `main` 分支
- 切换 GitHub Pages 发布源即可在"正式站 ↔ 维护页"之间快速切换
