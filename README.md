# 随机点名 · 液态玻璃抽卡系统

一个纯离线的课堂随机点名工具：抽卡舞台 + 名单管理 + 星级/保底 + 课堂积分 + 多名单库。
全部数据保存在浏览器 `localStorage`，不上传任何内容。

## 文件结构

| 文件 | 说明 |
|------|------|
| `index.html` | 页面结构与文案 |
| `styles.css` | 全部样式 |
| `app.js` | 业务逻辑 |
| `core.js` | 纯函数集合（概率/保底/种子/积分汇总/导入解析），app 与测试共用 |
| `xlsx.b64.js` | base64 内联 SheetJS；首次导入/导出 Excel 时才解码加载，不阻塞首屏 |
| `manifest.webmanifest` / `icon.svg` | PWA 静态清单与图标 |
| `sw.js` | Service Worker 离线缓存（`http(s)://` 下生效；`file://` 自动跳过） |
| `test/regression.test.js` | Node 回归测试：`node test/regression.test.js` |
| `回归清单.md` | 发布前端到端人工回归清单 |

> ⚠️ 前端文件必须放在同一目录，双击 `index.html` 即可使用（file:// 直开，无需服务器）。
> 若用 `http(s)` 托管，首次访问后即可离线打开；`file://` 下 Service Worker 不注册，但功能完整。

## 界面入口

- **顶部栏**：总人数 / 已抽中 / 剩余统计，以及音效、背景、📤 导出、⚙ 设置四个图标按钮。
- **底部工具条**：只保留「撤销 / 重做」两颗按钮（带 `Ctrl+Z` / `Ctrl+Shift+Z` 提示，无可撤销内容时自动置灰）。
- **设置 → 快捷入口**：导入、历史、统计、积分、座位表、PK、导出七张功能卡片；同一分组内的「危险操作」放红色 **重置全部数据** 按钮。
- **设置 → 关于**：项目仓库 <https://github.com/OStarsO/CAS>、作者博客 <https://ostarso.github.io>、作者 GitHub 主页 <https://github.com/OStarsO>（三个链接均新窗口打开；主页地址统一在 `app.js` 顶部的 `ABOUT` 常量里维护，置空则自动退化为占位提示链接）。

## 抽卡与概率

- 1–5★ 概率可在设置中调整（合计须为 100%），或切换为 1–5 倍权重模式。
- 保底可开关：十连至少 1 个 4★；50 抽未出 5★ 下一抽必出，触发时有金光、徽标、专属音效与历史标记。
- 幸运值：连续未出 5★ 时每抽提升 5★ 权重（可调步长，封顶 60）。
- 随机种子：设置后同种子 + 同名单可复现相同结果；历史记录附带种子哈希，可用"验证种子"核对；更改种子需二次确认，保底计数保留。

## 课堂积分

入口：设置 → 快捷入口「课堂积分」（或结果卡/名单行的积分徽标）。

- **加分对象**：默认"最近 10 抽"去重，可切换"最近一批 / 最近 20 抽 / 全部名单"。
- **单人 / 批量**：点击学生行勾选（支持全选），一次给多人加减分。
- **快捷加减**：
  - 抽中结果卡内有 `+1 / −1 / 积分` 按钮，直接给刚抽中的同学加分；
  - 名单行 hover 出现 `+1 / −1` 快捷按钮；
  - 名单行的积分徽标可点击，直接打开积分面板并预选该生。
- **原因与记录**：每条变动记录分值、原因（可自定义或用预设）、时间与批次；"积分流水"支持按学生、按时间（今天/近 7 天/近 30 天）筛选；支持"撤销最近一次"整批回退与"清空记录"。
- **实时汇总**：名单每行显示当前积分徽标；面板顶部显示候选/已选/累计加分/扣分；统计页有积分榜（前五）。
- **导出**："导出积分报表" 生成 Excel 三表：`最近抽到`（近 10 抽去重）、`积分变动`（流水）、`当前积分`（全员汇总，含加分/扣分次数）。

## 座位表

入口：设置 → 快捷入口「座位表」，或舞台下方「🪑 座位表」。

- **动态布局**：行/列可在编辑模式中配置，范围 1×1 到「名单人数」上限；默认按近方阵（如 47 人 → 7×7），网格中的空格不是座位、不参与抽取。座位数始终等于名单人数，名单增删会自动同步。
- **自由排座**：编辑模式可把任意座位拖到其他座位（互换）或空格（移动），末排座位可拖到左侧/右侧或独立成列/成行；「自动方阵」恢复默认，「应用布局」按指定行列重排。默认抽奖模式只读，投屏前请切回。
- **座位号**：首次创建按座位顺序自动编号；新增/导入的未编号学生可点「按拼音自动编号」，按姓名首字母排序分配空号，已有编号保持不变。删除学生只清空他占的座位，其余人的座位号既不重排也不清号（下次自动编号只补真正的空号）。
- **三种抽取模式**：舞台滑块切换「抽序号 / 抽座位 / 抽名字」，单抽与十连都遵循当前模式；名单、座位号、姓名与座位位置实时一致，拖动座位或改号后结果卡会同步更新。
- **导入/导出**：座位表导出为独立 Excel 工作表（座位号、姓名、学号、行、列、座位），主导出的 Excel 也包含该表；可从 Excel 导入并校验人数、姓名/学号匹配、座位号唯一性、行列范围与重复位置（座位号只要求唯一正整数，因此删过人、号段有缺口的表也能原样导回）。
- **3D / 2D**：CSS `perspective + rotateX + translateZ` 呈现讲台斜上方视角，选中座位升起发光；低配设备或行/列过多时自动 2D，也可手动切换。所有座位是独立 DOM，文字可选中、可被读屏器识别。

## 多名单库

入口：设置 → 全局 → 名单库。

- 每套名单库独立保存：**名单、抽卡历史、保底进度、积分记录、分组配色**。
- 适用场景：
  - 不同班级 / 不同课程各用一套，互不干扰；
  - 学期结束后"复制"一份留档，再清空当前库开始新学期；
  - 同一班级的"平时点名"与"小组 PK"分开记历史。
- 操作：新建（从空名单开始）、切换（自动保存当前库 + 加载提示）、重命名、复制、删除（仅剩一套时禁删，删除需二次确认）。
- 主题、概率、音效等全局设置不随名单库切换；分组配色与保底进度跟随名单库。

## 体验与无障碍

- **稀有度演出**：5★ 有金色光柱、压暗背景、结果卡特写与专属音效；4★ 紫色脉冲与轻微推镜；1–3★ 保持原样。低配设备或 `prefers-reduced-motion` 时改为静态光晕。
- **语音播报**：设置 → 声音 可开启系统语音，调节语速/音调/中英文音色；单抽揭晓与十连结束会播报姓名和星级（仅本机合成，不联网）。
- **键盘/读屏**：所有弹窗带 `role="dialog"`、`aria-modal`、`aria-labelledby`，打开自动聚焦、关闭还原焦点，Tab/Shift+Tab 在弹窗内循环，Esc 关闭。
- **移动端**：`viewport-fit=cover` + `env(safe-area-inset-*)` 适配刘海屏；键盘弹出时底部 Dock（撤销/重做）自动隐藏。
- **低配降级**：≤4GB 内存或 ≤4 核时自动关闭毛玻璃、星空与光晕；`prefers-reduced-motion` 下保留静态光效、移除动画。
- **保存策略**：编辑后 220ms 防抖写入；关闭页面、切后台、切换名单库前会立即 flush，避免丢数据。

## 数据与备份

- 所有数据自动写入 `localStorage`；占用超过约 80% 时会提示导出备份。
- 导出备份 JSON 可完整恢复；归档历史会先导出全量 JSON 再只保留最近 100 条与摘要。
- 运行时错误会记录到本地（最近 50 条），设置 → "导出错误日志" 可导出 JSON。

## 开发 / 测试

```bash
node test/regression.test.js   # 核心纯函数回归测试（概率/保底/幸运/种子/积分/导入）
```

浏览器控制台可用 `window.__test__` 调试核心函数（与 core.js 同一实现）。
发布新版本时请同步修改 `sw.js` 顶部的 `CACHE` 版本号，避免客户端继续命中旧缓存。
低配设备（≤4GB 内存或 ≤4 核）自动关闭毛玻璃、星空与光晕特效；`prefers-reduced-motion` 时动画也会精简。
